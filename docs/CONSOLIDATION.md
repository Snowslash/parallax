# Lesson consolidation

The main lab contains two distinct tasks: Guidewire across a fracture and Femoral wire position. The landing opens the lesson chooser; free exploration is no longer a competing entry point.

Both lessons use the shared `demo/lesson-workspace.css` composition and pinned estate UI. The current X-ray and its acquisition controls come first, with saved views and the answer alongside. Secondary 3D context follows; it does not interrupt comparison and answering on a phone. The existing rendering engines, finite-source geometry, fixed image mapping, preset cases, model hashes and answer gates remain intact. A common interface is not a claim that the anatomical assets or rendering approaches are identical.

The proximal-femur criteria remain exercise-specific tip-to-marker measurements, not clinical TAD. The fracture exercise still permits uncertainty; acquiring a second view does not prove that it resolves the question. The entire wire remains hidden from the explanatory view until the learner confirms an answer.

`explore.html` is now the archive. The original `guided.html`, `beam3d.html` and `mesh-spike.html` destinations remain functional. Projection fundamentals preserves its distinctive diagonal-breach case and cached images; no old image has been relabelled as newly rendered evidence. Archived models, licences and numerical records are retained.

No model substitution, new anatomical import, framework migration or renderer rewrite accompanies this presentation change. A future shared femur would require checking proximal landmarks and shaft/canal coverage separately before replacing either active lesson's assets.
